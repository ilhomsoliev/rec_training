# Как сдавать практикум

Для начала сделай **Fork** этого репозитория, потом клонируй **свою** копию. Каждый этап — маленький коммит, который можно показать руководителю. Не обязательно открывать 10 разных PR: достаточно одного PR с понятными коммитами по этапам или нескольких PR по согласованию.

~~~bash
git switch -c practice/recommendations
# пишешь код
npm run check
npm test
git add src/engine.ts tests/
git commit -m "feat: implement activity filtering"
git push -u origin practice/recommendations
~~~

Открой PR из `practice/recommendations` в `main` **в своём fork**. В описании: что реализовано, какие тесты проходят, что пока непонятно, один пример результата `npm run demo`.

Если тесты не проходят, это не катастрофа: сначала закончи конкретный этап. Не присылай чужие готовые реализации и не включай в коммит `node_modules`.

**Для руководителя:** проверяйте не только зелёные тесты, но и умение ученика объяснить: почему настроение мягкое условие, зачем `Set`, как работает случайный индекс и почему нельзя менять исходный массив.
