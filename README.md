# Учимся рекомендовать занятия 🎲

**Практикум по TypeScript: от набора правил до собственного рекомендательного алгоритма.**

Представь: друзья не знают, чем заняться. У них есть час, 300 ₽ на человека, настроение спокойное и возможность остаться дома. Как программе выбрать занятие из каталога — и не предлагать то, что уже показывали?

На этом курсе ты напишешь **один главный файл — `src/engine.ts`**. Мы дадим тебе данные, типы, примеры отдельных приёмов и тесты, но **не дадим готовый движок**. Его шаг за шагом соберёшь ты.

> Здесь нет машинного обучения, API или React Native. Только TypeScript, логика, массивы, чистые функции и тесты. Это специально: сначала научимся выбирать занятие правильно, потом можно будет подключить алгоритм к любому интерфейсу.

## Как запустить

Установи Node.js **22+**, Git и VS Code. Сделай Fork этого репозитория на GitHub, а затем:

~~~bash
git clone https://github.com/ТВОЙ_ЛОГИН/rec_training.git
cd rec_training
npm install
npm run check
npm run demo
npm test
~~~

**Важно:** в начале `npm test` покажет ошибки. Это ожидаемо! В `src/engine.ts` стоят учебные заготовки с `TODO`. Тесты постепенно начнут проходить по мере выполнения заданий.

### Четыре функции, которые ты соберёшь

1. `validateFilters` — отловить неправильные параметры (например, ноль участников).
2. `filterActivities` — убрать занятия, которые физически не подходят по условиям.
3. `rankActivities` — оценить оставшиеся варианты по мягким предпочтениям.
4. `recommend` — убрать уже показанные, выбрать из лучших и вернуть осмысленный результат.

В файле `src/engine.ts` специально оставлены подсказки и временные возвращаемые значения. Удаляй `TODO` по мере прохождения курса. Не копируй весь алгоритм из интернета: попробуй объяснить каждую проверку своими словами.

## Как понять, что готово

- `npm run check` проходит без ошибок TypeScript.
- `npm test` проходит полностью.
- `npm run demo` выдаёт занятие и объясняет выбор.
- Параметры `0 участников` и `-100 ₽` дают ошибку, а `0 ₽` — **разрешённый бесплатный бюджет**.
- «Другое» не повторяет занятие в пределах одной серии.
- Начало новой серии позволяет получить ранее показанные варианты.
- В исходном каталоге ничего не меняется.
