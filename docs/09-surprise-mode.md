# 09. «Удиви меня»: без старых ограничений

В обычном подборе человек вводит условия. В режиме «Удиви меня» мы запускаем тот же алгоритм, но с **параметрами без ограничений**.

Открой `src/types.ts` и сравни:

```typescript
export const SURPRISE_FILTERS: Filters = {
  participants: null,
  availableMinutes: null,
  budgetPerPerson: null,
  location: "any",
  mood: "any",
};
```

Это не «ноль участников» и не «бесплатно»: `null` означает «не ограничивать». При этом **неактивные занятия всё равно исключаются**.

Как не зависеть от случайной сортировки каталога? Для свободного режима без интересов оценка всех идей часто одинаковая. Если просто выбирать из первых десяти после сортировки по ID, часть каталога будет редко появляться. Подумай, как сделать режим действительно разнообразным.

**Базовое задание:** `recommend(catalog, SURPRISE_FILTERS, [])` даёт любой активный вариант (если он есть). **Дополнительное:** в режиме без предпочтений перемешай допустимые варианты до выбора или выбери из всего каталога; сделай решение осознанным и тестируемым.

**Важно:** при отдельном запуске новой серии `shownIds = []`. Смена параметров обычно означает новую серию.
