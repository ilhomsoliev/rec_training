# 04. Жёсткая фильтрация: сначала реальность, потом вкусы

Функция `filterActivities` принимает **каталог и фильтры**, возвращает **новый массив** только из подходящих занятий.

Условия работают одновременно через логическое И (`&&`). Участников должно быть **не меньше минимума и не больше максимума** занятия. Время и стоимость не должны превышать доступные. Выбранное место должно присутствовать в списке мест занятия. Неактивные занятия исключаются всегда.

## Пример другой задачи: отбор поездок

```typescript
type Trip = { name: string; seats: number; hours: number; active: boolean };

function availableTrips(trips: readonly Trip[], people: number, hours: number): Trip[] {
  return trips.filter(
    (trip) => trip.active && trip.seats >= people && trip.hours <= hours,
  );
}
```

Это **целая работающая функция**, но для поездок. Твоя функция будет похожа, только полей больше и есть значения «без ограничений».

## Частые ошибки

1. Путать `null` и `0`: «неважна цена» отличается от «только бесплатно».
2. Делать `activity.minParticipants === filters.participants`: занятие «от 2 до 5» подходит для троих.
3. Использовать настроение как жёсткое условие — это предпочтение, а не запрет.
4. Изменять исходный массив или объект вместо получения нового массива.

**Проверка:** занятие стоимостью ровно 500 ₽ должно подходить при бюджете 500 ₽.
