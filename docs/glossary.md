# Короткий словарь

**Каталог** — список занятий, из которого выбираем. **Активность** — одна запись каталога. **Фильтр** — условие отбора. **Жёсткое ограничение** — правило, которое нельзя нарушить. **Мягкое предпочтение** — желательный признак, дающий баллы.

**Score** — оценка пригодности; **ranking** — сортировка по score; **eligible** — занятия, прошедшие ограничения; **candidate** — претендент из верхней части рейтинга; **shownIds** — уже показанные ID; **серия** — последовательность рекомендаций при одних условиях.

**Чистая функция** — при одинаковых аргументах возвращает один результат и не изменяет внешнее состояние. Для функции со случайностью предсказуемость достигается передачей `random` как аргумента.

**Edge case** — граничный случай, например нулевой бюджет или пустой каталог. **Unit-тест** — автоматическая проверка небольшой части программы.
