# 06. Ранжирование: хорошие идеи выше

`rankActivities` не выбирает одну рекомендацию — он **упорядочивает весь список** вариантов по score.

```typescript
type Item = { id: string; score: number };
const items: Item[] = [
  { id: "b", score: 2 },
  { id: "a", score: 5 },
  { id: "c", score: 2 },
];

const sorted = [...items].sort(
  (left, right) => right.score - left.score || left.id.localeCompare(right.id),
);
```

Получится `a(5), b(2), c(2)`. Когда баллы одинаковые, сравниваем ID. Это делает порядок предсказуемым в тестах.

**Почему копия?** `sort` меняет массив на месте. Если функция получает общий каталог, такое поведение может испортить порядок для другого участка приложения.

У тебя `rankActivities` сначала создаст новый массив объектов `{ activity, score, reasons }` через `map`, а затем отсортирует его. Ранжирование не должно выкидывать занятия с нулевой оценкой: они всё ещё подходят по жёстким условиям.
