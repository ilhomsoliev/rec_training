# 11. Как всё соединится в один файл

Открой [src/engine.ts](../src/engine.ts). В нём уже есть **все импорты, типы, сигнатуры функций и TODO** — специально, чтобы ты видел, где будут находиться части твоего алгоритма.

~~~text
src/types.ts             ← типы и допустимые значения
      ↓
src/data/catalog.ts      ← входные занятия
      ↓
src/engine.ts
  ├─ validateFilters    ← правильные ли параметры?
  ├─ filterActivities   ← какие занятия подходят?
  ├─ rankActivities     ← какие из них предпочтительнее?
  └─ recommend          ← какая одна рекомендация?
      ↓
src/demo.ts              ← показывает результат в консоли
      ↓
tests/*.test.ts          ← проверяют правильность
~~~

### Как должна выглядеть полная функция recommend в общих чертах

Не код-решение, а **порядок действий**:

1. Получи ошибки проверки. Если есть — верни `invalid`.
2. Найди все подходящие занятия. Если их нет — `empty`.
3. Убери ID из `shownIds`. Если после этого пусто — `exhausted`.
4. Ранжируй оставшиеся варианты и возьми не более 10.
5. Определи случайный индекс безопасно, даже если `random` подменили.
6. Верни `success` с занятием, баллами, причинами, `eligibleCount` и `remainingCount`.

**Счётчики:** `eligibleCount` — сколько занятий прошло жёсткую фильтрацию до удаления показанных. `remainingCount` — сколько ещё можно предложить после текущей выдачи.

Важно: чистые функции не должны ни сохранять историю на сервере, ни вызывать `setState`, ни менять каталог. UI просто вызывает `recommend` и отображает один из четырёх результатов.
