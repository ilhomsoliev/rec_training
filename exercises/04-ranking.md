# Задание 04. Расставь занятия по порядку

**Теория:** [ранжирование](../docs/06-ranking.md). Используй `rankActivities` из предыдущего задания.

После вычисления score:
1. Отсортируй результаты от большего балла к меньшему.
2. Если баллы равны — расположи занятия по ID по алфавиту.
3. Не меняй исходный массив активностей.

### Проверь

Если есть три занятия со score 5, 2 и 5, первые два должны иметь 5. При равном score порядок определяется ID.

**Готово:** `tests/03-ranking.test.ts` проходят, в работе не используется `activities.sort(...)` над входным массивом.
