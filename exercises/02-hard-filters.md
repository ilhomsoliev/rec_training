# Задание 02. Отсей неподходящие активности

**Теория:** [жёсткие фильтры](../docs/04-hard-filters.md). **Файл:** `src/engine.ts` → `filterActivities`.

### Тебе нужно

Оставить только `isActive: true`. Затем проверить количество участников (включая обе границы), длительность, цену на человека и наличие нужного места в `locations`. При `null` / `"any"` ограничение не действует.

Ошибочные фильтры должны давать пустой массив. **Настроение и интересы здесь не участвуют!**

### Проверь

- Один человек не подходит для занятия с `minParticipants=2`.
- Бюджет 0 подходит бесплатным идеям.
- Цена ровно равна бюджету → занятие допустимо.
- Место может быть в одном из нескольких значений `locations`.
- Входной каталог не изменился.
