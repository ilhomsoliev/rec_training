# Задание 09. Объясни работу алгоритма без экрана приложения

**Теория:** [связи файлов](../docs/11-integration.md).

Заверши `src/demo.ts`: выведи обычную рекомендацию, причину выбора, количество оставшихся вариантов, результат «Другое» и режим «Удиви меня».

Сделай две дополнительные демонстрации: условия, при которых нет подходящих активностей, и намеренно неправильный бюджет.

**В PR:** приложи короткий вывод `npm run demo` и расскажи, откуда берётся список, где проверяются фильтры и что именно возвращается наружу.

**Готово:** человек без знания TypeScript может понять по выводу терминала, как программа выбирает занятие.
