# Задание 06. Реализуй «Другое» без повторов

**Теория:** [серии и состояния](../docs/08-series-and-results.md). Доработай `recommend`.

Предположим, вызов вернул ID `a`. Интерфейс сохранит его в `shownIds` и передаст при следующем вызове. Твоя функция **не должна возвращать `a` повторно**, пока серия продолжается.

### Четыре результата

`invalid` — плохие входные параметры; `empty` — не осталось подходящих **после жёстких ограничений**; `exhausted` — все подходящие варианты уже были показаны; `success` — нашлась новая идея.

Не путай `empty` с `exhausted`! При пустом каталоге результат `empty`. При каталоге из одного подходящего занятия, которое уже показали, — `exhausted`.

**Готово:** тесты в `tests/04-recommendation.test.ts` проходят, в новом вызове с пустым `shownIds` прежний вариант снова доступен.
