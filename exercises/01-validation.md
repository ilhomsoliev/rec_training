# Задание 01. Научись говорить «эти условия некорректны»

**Сначала прочитай:** [TypeScript-инструменты](../docs/02-typescript-tools.md) и [валидацию](../docs/03-validation.md).

Открой `src/engine.ts` и найди `validateFilters`. Сейчас она всегда возвращает `[]`. Напиши проверки самостоятельно.

### Что сделать

- Если `participants` задано, это должно быть **целое число от 1 до 10**.
- Если `availableMinutes` задано, оно должно быть **конечным числом больше 0**.
- `budgetPerPerson` может быть 0, но не может быть отрицательным, бесконечностью или `NaN`.
- `location` и `mood` должны быть из известных значений или `"any"`.
- Для `null` соответствующее ограничение не действует.
- Можно возвращать **несколько ошибок одновременно**.

### Проверка

`npm run check` и тесты `tests/01-validation.test.ts`. Проверь вручную `participants: 1.5` и `budgetPerPerson: 0`.

**Готово, если:** некорректные параметры дают непустой массив ошибок, корректные — пустой. Не используй `any`.
