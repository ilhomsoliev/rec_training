# Задание 08. Поймай собственные ошибки

**Теория:** [тесты](../docs/10-testing.md).

Создай `tests/my-cases.test.ts` с **минимум четырьмя собственными тестами**:

1. Одно занятие подходит по всем граничным условиям.
2. Некорректный ввод даёт `invalid`.
3. При пустом каталоге получается `empty`.
4. При всех показанных занятиях получается `exhausted`.

Дополнительно проверь, что не меняется входной массив и что теги не начисляют дополнительные баллы за дубли.

**Как сдавать:** приложи вывод `npm test` и кратко объясни, какой баг поймает каждый тест.

**Готово:** тесты запускаются и действительно проверяют разные ситуации, а не повторяют одно условие.
